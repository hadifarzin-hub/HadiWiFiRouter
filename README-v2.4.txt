Hadi WiFi Router v2.4

Setup reliability update:
- Setup-Packet-Engine now reuses an existing official WinDivert installation from an earlier HadiWiFiRouter version before attempting a download.
- This prevents upgrades from failing simply because github.com is temporarily unreachable.
- If no previous WinDivert files exist, Internet access is still required once to download official WinDivert 2.2.2.
- Setup-All title corrected to v2.4.
- Protected Windows Users feature from v2.3 is retained.
