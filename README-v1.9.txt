Hadi WiFi Router Portable v1.9

New in v1.9:
- Target-aware schedules. Each schedule row selects Day, Start, Stop, and Apply to.
- Targets: Whole traffic, YouTube, TikTok, Instagram, Snapchat.
- Multiple time windows per day and per service are supported.
- Whole traffic rules control whether the hotspot is on.
- Service rules define when that service is allowed; outside the configured periods the packet engine blocks that service.
- Schedule rules refresh automatically before Windows login because the service runs as SYSTEM.
- Website blocking and speed-control service profiles continue to share the same service-domain definitions.

Run Setup-All.cmd as Administrator once from this permanent v1.9 folder.
